# CV Project Description

**E-Commerce Sales Performance Dashboard | Power BI**

- Built an interactive Power BI dashboard analysing 400 e-commerce orders and 100 customers.
- Developed KPI reporting for £195.55K completed revenue, 260 completed orders and £752 average order value.
- Analysed category, customer, product, monthly revenue and order-status performance using Power BI, DAX and data modelling.
- Transformed transactional data into business-focused visualisations to support performance monitoring and decision-making.
