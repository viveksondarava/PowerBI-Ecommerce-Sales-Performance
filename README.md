# E-Commerce Sales Performance Dashboard — Power BI

## Project Overview
Built an interactive Power BI dashboard to analyse e-commerce sales performance, customer behaviour, product performance and order status.

## Key Metrics
- Completed Revenue: **£195.55K**
- Completed Orders: **260**
- Average Order Value: **£752.12**
- Total Orders: **400**

## Dashboard Analysis
- Revenue by Category
- Top 5 Customers by Revenue
- Top 5 Products by Revenue
- Monthly Revenue
- Order Status Breakdown

## Tools & Skills
Power BI Desktop, Power Query, DAX, Data Modelling, Data Visualisation, KPI Development, Business Analysis and Data Storytelling.

## Data
Synthetic e-commerce dataset containing customers, orders, order items and products.
