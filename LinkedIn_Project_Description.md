# LinkedIn Project Description

Built an interactive **E-Commerce Sales Performance Dashboard** in Power BI to analyse sales, customer and product performance.

The dashboard covers £195.55K completed revenue, 260 completed orders, £752.12 average order value, category performance, top customers, top products, monthly revenue and order-status analysis.

Skills: Power BI, DAX, Power Query, Data Modelling, Data Visualisation, Business Analysis and Data Storytelling.
